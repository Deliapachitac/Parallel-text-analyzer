# lexan.c
Αρχικα ξεκιναμε το προγραμμα ελεγχοντας, διαβαζοντας και αποθηκευοντας τα δεδομενα απο την γραμμη εκτέλεσης.Οι σημαίες -i/-l/-m/-t/-e/-o
μπορούν να χρησιμοποιηθούν με οποιαδήποτε σειρά. Πριν ξεκινησουμε να χωριζουμε το αρχειο και να το στελνουμε στα splitter θα πρεπει να
διαβασουμε το πληθος των γραμμων και να φτιαξουμε ενα πινακα με πρωτο byte της καθε γραμμης ωστε να ξερουμε απο που θελουμε να αρχιζουμε 
να διαβαζουμε το αρχειο.

O πατερας υπολογισει ποσες γραμμες θα διαβασει ο καθε splitter και το πρωτο byte της γραμμη που θελουμε να 
ξεκινησουμε το διαβασμα τα μεταφερουμε μεσω 2 ξεχωριστων pipe στο κομματι που ξεξιναμε την εφαρμογη του splitter. Για καθε splitter 
φτιαχνουμε εναν πινακα που θα περιεχει το ονομα του file που θα διαβασουμε , το exclusion list, τις γραμμες που πρεπει να διαβασουμε , 
τo byte της γραμμης που θα ξεκινησουμε το διαβασμα , το πληθος των builder και ολα τα pipes που θα χρησιμοποιηθουν για την επικοινωνια μεταξυ 
splitter και builders.Αφου δημιουργησουμε τον πινακα θα καλεσουμε την execvp με το προγραμμα ./splitter.

Αντιστοιχα θα φτιαξουμε εναν πινακα  και μεσα στην loop που χειριζομαστε τα builder.Μεσα στον πινακα θα αποθηκευσουμε ενα pipe το οποιο θα
διαβαζουμε τα δεδομενα απο το splitter, της γραμμες του αρχειου που θα μας βοηθησουν της δημιουργια των hash table και αλλο ενα pipe για 
την επικοινωνια του builder με τον root.Αφου δημιουργησουμε τον πινακα θα καλεσουμε την execvp με το προγραμμα ./builder.

Αφου ολοκληρωθουν ολες οι διεργασιες που περιγραφω στις παραγραφους splitter.c και  builder.c , δημιουργουμε εναν πινακα τον οποιο καθε 
φορα θα γεμιζει θα κανουμε reallocate τον πινακα.Ο συγκεκριμενος πινακας θα περιεχει την λεξη και την συχνοτητα εμφανισης της λεξης που  την
υλοποιησαμε με την βοηθεια ενος struct.Αφου διαβασουμε ολα τα δεδομενα απο καθε builder θα τα ταξινομησουμε με την βοηθεια της συναρτησης
qsort. Στο output file θα εκτυπωσουμε πρωτα ολους τους χρονους των καθε builder, τις top n δημοφιλεστερες λεξεις , ποσα signals σταλθηκαν 
απο τους splitters και τους builders και τον χρονο της lexan.c.

# splitter.c
Ο καθε splitter δημιουργει ενα δικο του hash table με τις λεξεις του exclusion list που αναφερω παρακατω αναλυτικα πως γινεται.Μετα την
δημιουργια του αρχιζει και διαβαζει δεδομενα απο το file κανοντας διαφορους ελεγχους.Οι ελεγχοι θα ειναι οι εξης:
-να αφαιρεθουν τα σημεια στιξης 
-τα κεφαλαια γραμματα να γινουν μικρα 
-να αφαιρεθουν οι αριθμοι 
-η λεξη να μην ανηκει μεσα στο exclusion list
Αφου καναμε τις απαραιτητες αλλαγες θα πρεπει να επιλεξουμε σε ποιο builder θα στειλουμε την λεξη . Για αυτο τον λογο δημιουργησαμε ενα 
hash fuction γαι τους builders (hash_for_builders), ωστε ολες οι ιδιες λεξεις να πανε στον ιδιο builder μεσο ενος pipe.
Το διαβασμα και το γραψιμο στα pipes θα ολοκληρωθει αφου εχουμε διαβασει το πληθος των γραμμων που εχει εχει προκαθοριστει απο το 
lexan.c

# builder.c
Ο καθε builder αφου εχει διαβασει και αποθηκευσει τα δεδομενα που του σταλθηκαν μεσω arguments, θα ξεκινησει να διαβαζει και να 
χωριζει τα δεδομενα που στελνονται μεσω των pipes απο τους splitters.Θα διαβαζει πολλα bytes ταυτοχρονα και θα χωριζει τις λεξεις καθε 
φορα που του στελνεται ενα κενο (spacetab). Αυτες οι λεξεις θα αποθηκευτουν μεσα στο hash table χρησιμοιποιωντας την strdup (δημιουργειτε 
ενα διπλοτυπο της λεξης για να μην εχουμε θεμα με τα pointer).Αφου εχουμε διαβασει ολες τις λεξεις και εχουν αποθηκευτει και οι συχνοτητες 
εμφανισης των λεξεων που περιγραφω παρακατω στην παραγραφο των Hash θα πρεπει να διαπερασω ολο το hash table και να στελνω μεσω pipes στον 
root το μηκος της λεξης, την λεξη και την συχνοτητα. Τελος θα στειλω την τιμη 0 για να καταβει η ριζα οτι τελειωσα  το γραψιμο των λεξεων 
και οτι θα σταλθουν αλλες 2 τιμες o real time και ο CPU time.

# Hash.c - Hash.h 
Xρειαζομαστε μια δομη η οποια θα εχει πολυπλοκοτητα εισαγωγης και αναζητησης Ο(1), το hash table και 
το υλοποιησαμε με separate chaining. Ουσιαστικα ειναι μια δομή δεδομένων που χρησιμοποιεί έναν πίνακα 
και μια συνάρτηση κατακερματισμού (hash function) για να αποθηκεύσει τα generic δεδομενα μας(Pointer value). Επιπλεον
θα αποθηκευει και τoν αριθμο των εμφανισεων (counter) της τιμης που αποθηκευτηκε μεσα στο value,στην περιπτωση μας θα ειναι 
μια λεξη και η συχνοτητα εμφανισης της. Για κάθε κλειδί η συνάρτηση κατακερματισμού υπολογίζει έναν δείκτη (index)
στον πίνακα και τα αποθηκευει. Αν δύο ή περισσότερα κλειδιά έχουν τον ίδιο index αποθηκεύονται σε μια λίστα.

Στην ασκηση μας θα χρησιμοποιησουμε 2 φορες τα hash table. Αρχικα θα δημιουργησουμε ενα hash table για να αποθηκευσουμε 
τα δεδομενα της exclusion list για την οποια δεν θα μας νοιαζει η συχνοτητα εμφανισης της λεξης.Αυτο το κανουμε διοτι οταν
θα θελουμε να ελεγξουμε αν μια λεξη ανηκει μεσα στην exclusion list θα εχει πολυπλοκοτητα Ο(1) το οποιο μειωνει δραστικα 
τον χρονο αν εχουμε μια λιστα 1000 λεξεις οπως χρησιμοποιουμε στην ασκηση που θα χρειαζοταν να προσπελασουμε ολη την λιστα.
Επισης θα εχουμε χρηση του hash table και οταν θα αποθηκευουμε τις λεξεις απο το κειμενο στο οποιο εδω θα παιζει ρολο η 
συχνοτητα εμφανισης της λεξης. Καθε που προσθετουμε μια λεξη που υπαρχει ηδη στο hash table θα αυξανεται ο counter της struct
και δεν θα προσθεται ξανα η ιδια λεξη.Περα απο τις βασικες συναρτησεις (create_hash_table,hash_string,hash_add,hash_find) εχουμε 
προσθεσει και καποιες επιπλεον συναρτησεις ,οπως το get_counter και το hash_get_value που επιστρεφουν την συχνοτητα και την 
λεξη . Τελος προσθεσαμε την hash_first και την hash_next οι οποιοες ειναι βοηθητικες συναρτησεις για την προσπελαση του hash table.
